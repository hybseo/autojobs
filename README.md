# 자동차부품·전장 채용 모음

자동차부품·전장 기업의 **공식 채용페이지** 공고만 모아 보여주는 정적 사이트입니다.
채용 플랫폼(사람인·잡코리아 등)을 크롤링하지 않습니다.

## 시작하기

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # dist/ 생성
```

배포 전 `astro.config.mjs` 의 `site` 를 실제 도메인으로 바꾸고,
`public/robots.txt` 의 sitemap 주소도 함께 고치세요.

## 공고 갱신

```bash
python scripts/fetch_jobs.py
```

`src/data/jobs.json` 을 새로 씁니다. 기업을 추가하려면 스크립트 상단
`COMPANIES` 에 `(기업명, URL슬러그, prefix)` 한 줄을 더하면 됩니다.
`prefix` 는 채용사이트 도메인의 맨 앞부분입니다.
예를 들어 `hanonsystems.recruiter.co.kr` 이면 `hanonsystems`.

`.github-workflows-daily.yml` 을 `.github/workflows/daily.yml` 로 옮기면
매일 오전 6시에 자동 갱신됩니다.

### 수집 API

```
목록  POST /position/v1/jobflex
상세  GET  /position/v2/jobflex/{positionSn}
호스트  https://api-recruiter.recruiter.co.kr
헤더    prefix: {기업코드}.recruiter.co.kr
```

인증 토큰은 필요 없습니다. 대신 두 가지를 반드시 지켜야 합니다.

- **`prefix` 헤더가 없으면 500** 이 떨어집니다. 기업 식별자 역할입니다.
- **접수중 판별은 `submissionStatus == "IN_SUBMISSION"`** 입니다.
  `openStatus` 는 접수중을 뜻하지 않습니다. 마감된 지 수백 일 지난 공고도 `OPEN` 입니다.
  이걸 잘못 쓰면 33건이어야 할 목록이 365건으로 부풀어 오릅니다.

## 페이지 구조

| 경로 | 역할 |
|---|---|
| `/` | 전체 공고. 마감 임박순. 기업·경력 필터, 검색 |
| `/company/{slug}/` | **핵심 랜딩 페이지.** 진행중 공고 + 지난 채용 이력 + 직접 쓰는 해설 |
| `/job/{id}/` | 개별 공고 상세. 본문이 확보된 공고만 생성 |
| `/sitemap.xml` | 자동 생성 |

구직자는 직무명보다 **기업명으로 검색합니다**. "한온시스템 채용" 같은 검색이
"자동차 전장 개발 채용"보다 훨씬 많습니다. 그래서 기업 페이지가 트래픽의 관문입니다.
마감 공고를 지우지 말고 아카이브로 남기면 시간이 갈수록 이 페이지가 강해집니다.

## JobPosting 구조화 데이터

구글 채용정보 검색에 노출되려면 각 공고 페이지에 `JobPosting` 스키마가 필요합니다.
`src/lib.js` 의 `jobPostingSchema()` 가 처리합니다.

**본문이 없는 공고에는 스키마를 넣지 않습니다.** 구글은 페이지에 실제 직무 설명이
있을 것을 요구하는데, 제목만 있는 페이지에 스키마를 다는 건 위반입니다.
공고 본문이 이미지 한 장인 경우(HL만도 등)가 여기 해당하며,
이 공고들은 상세 페이지를 만들지 않고 목록에서 원문으로 바로 링크합니다.
`multiRole: true` 로 표시되어 "여러 직무 포함 가능" 배지가 붙습니다.

## 검색엔진 등록

1. **구글 서치콘솔** — 도메인 등록 후 sitemap 제출
2. **네이버 서치어드바이저** — 사이트 등록 후 sitemap 제출.
   자체 도메인도 네이버 웹사이트 영역에 색인됩니다
3. 두 곳의 소유확인 코드를 `src/layouts/Base.astro` 의 meta 태그에 넣으세요

## 콘텐츠에 대하여

공고 목록만으로는 검색 노출이 어렵습니다. 중복 콘텐츠로 판정되기 때문입니다.
`/company/{slug}/` 의 "이 회사는 어떤 사람을 뽑나" 영역과
`/job/{id}/` 의 헤드헌터 코멘트를 **직접 채우세요.**
공고 원문에 없는 이 설명이 이 사이트를 다른 채용 사이트와 구분해 줍니다.

## 데이터 범위

수집되는 것은 각 기업이 자사 ATS 에 공개한 접수중 공고입니다.
아래는 포함되지 않습니다.

- 채용 플랫폼에만 올린 공고
- 헤드헌터에게만 도는 비공개 포지션
- 이미지 공고 안의 세부 직무

"전체 채용 정보"가 아니라 "기업 공식 채용페이지 공고 모음"으로 표현하는 것이 정확합니다.
